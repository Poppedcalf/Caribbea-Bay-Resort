# Caribbea Bay Resort: direct-booking website prototype

Single-page demo by Local Edge. Everything (HTML, CSS, JS, photos) is in `index.html`, so it needs no build step.

## Publish on GitHub Pages
1. Put `index.html` and this README in the root of the repo.
2. Repo Settings > Pages > Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
3. The site appears at `https://<username>.github.io/<repo-name>/` after about a minute.

## Before showing the resort
- Confirm meal times, pool hours and suite, family and camping rates.
- Replace the illustrative map with the official site plan.
- Swap in a vector or high-resolution logo if the resort has one.

Content is based on the resort's public posts. Not the official site.
